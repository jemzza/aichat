# AI Chat для iPhone

Запуск: двойной клик по `Build.command` в Finder. Скрипт сам установит
XcodeGen (если его нет), сгенерирует проект, соберёт его и запустит в
симуляторе. Если macOS не даёт открыть файл — правый клик → «Открыть».

Нужен Xcode 26 (собирается с минимальной iOS 18).

## Время

~8 часов чистого времени (по таймстемпам коммитов — с 08.10 16:54 по
09.10 06:28 с перерывами).

## Инструменты

Claude Code, модель Opus 5.5. Работа шла по `docs/plan.md` шагами, правила
агента — в `CLAUDE.md`, транскрипты — в `ai-logs/` (вычищены ключи, email и
пути). Независимые части (AI-клиент, голос, папки, бонусы, настройки) делались
параллельными сессиями в отдельных git worktree на ветках `feat/*` и вливались
в `main`.

## AI в приложении

Groq, OpenAI-совместимый `/chat/completions` со стримингом:

- текст — `openai/gpt-oss-120b` (`reasoning_effort: low`, без рассуждений в ответе);
- запросы с фото — `qwen/qwen3.8-27b` (единственная vision-модель Groq, preview);
- офлайн — Apple Foundation Models на iOS 26+ по кнопке «Answer offline»
  под неотправленным сообщением (если системная модель доступна).

Ключ хранится в `AIChat/Data/Secrets/Secrets.generated.swift` в обфусцированном
виде (XOR с солью, генерируется `scripts/gen_secrets.py` из переменной
окружения). Это защита от сканеров секретов, а не от реверс-инжиниринга:
настоящая защита потребовала бы своего прокси-сервера.

Бесплатный тариф Groq: 30 запросов/мин, 1 000 в день, 8 000 токенов/мин.
Контекст запроса обрезается (последние 20 сообщений, ~6 000 символов), чтобы
укладываться в лимит. При исчерпании — плашка «Try again in N s».
Groq может быть недоступен из некоторых регионов — тогда ошибка 403 с
понятным текстом.

## Архитектура

MVVM + offline-first: база GRDB — единственный источник правды, UI подписан
на неё через `ValueObservation`, сеть только пишет в базу. Единственное
исключение — живой черновик стримящегося ответа: его в памяти отдаёт
`ChatService`, в базу текст пишется не чаще ~2 раз в секунду и в конце.

- `App/` — композиция (`AppContainer`, разбор DEBUG launch-аргументов);
- `Features/` — экраны (View + `@Observable` ViewModel);
- `Domain/` — модели, протоколы, `ChatService` (без UI и GRDB);
- `Data/` — GRDB, Groq/SSE, Foundation Models, речь, настройки, секреты.

Зависимости — только GRDB через SPM. Подробнее — `docs/task.md` (раздел
«Решения»), ход работы и отклонения — `docs/plan.md`.

## Сделано

Обязательное:

- Стриминг ответа по токенам, кнопка «Stop» — полученный текст сохраняется.
- Несколько чатов, история в базе; сайдбар с поиском и группировкой по датам,
  переименование и удаление чата.
- Состояния: ожидание первого токена, пустой экран с подсказками, ошибки
  «нет сети» / 429 / 401 / 403 / 5xx — у каждой свой текст и «Retry».
- Без сети сообщение сохраняется и уходит само, когда сеть появилась (а также
  при запуске и возврате в приложение), ровно один раз. Ответ, оборванный
  закрытием приложения, помечается как прерванный с «Retry».
- Markdown в ответах: заголовки, списки, блоки кода с кнопкой «Copy».
- Светлая и тёмная тема, Dynamic Type, iOS 18 и iOS 26, iPhone и iPad.
- XcodeGen + `Build.command`, ключ в обфусцированном виде, работает сразу
  после сборки.

Бонусы:

- Офлайн-ответ моделью на устройстве (iOS 26, Foundation Models).
- Mac Catalyst (сборка — команда в `docs/task.md`, строка «Mac»).
- Фото во вложении (до 3 на сообщение, уменьшаются и хранятся в базе).
- Русская локализация (по языку системы).
- Голос: озвучка ответов и диктовка «зажми и говори».
- Папки для чатов: перетаскивание и «Move to folder».
- Настройки: тема, локальные уведомления о готовом ответе в фоне,
  «Delete all chats».

## Не сделано и известные баги

- Таблицы в Markdown не рисуются — показываются обычным текстом.
- В симуляторе iOS 26 на iPhone долгое нажатие на строку чата иногда
  открывает чат вместо контекстного меню. На iOS 18 и iPad не
  воспроизводилось, на устройстве не проверено.
- Пока клавиатура прячется протяжкой ленты, поле ввода не едет за ней, а
  встаёт на место в конце жеста — так SwiftUI обновляет safe area.
- При самых крупных размерах шрифта (AX) верхняя панель и кнопки ограничены
  в росте, текст сообщений — нет.
- Модель на устройстве: первый ответ после холодного старта — ~25 с; русского
  нет в списке поддерживаемых языков (отвечает, но слабее). «Answer offline»
  не предлагается для сообщений с фото.
- Vision-модель Groq — preview, может измениться или пропасть.
- Диктовка: настоящее распознавание проверено только на iPhone — в симуляторе
  нет офлайн-моделей речи. Системный текст запроса разрешения
  `SFSpeechRecognizer` упоминает отправку в Apple; на устройстве распознаём
  локально, через сервер Apple — только если офлайн-модели языка нет.
- Если на Mac включён VPN, DNS симулятора может не находить `api.groq.com` —
  приложение показывает «No internet connection». Без VPN работает.
- Многооконность на iPad выключена.

## Как проверяли

- Симуляторы: iOS 18.5 (iPhone 16, iPad Pro 11"), iOS 26.4 (iPhone 17,
  iPad Air 13"); устройство — iPhone на iOS 26.
- Сценарии: живой стриминг Groq, «Stop», несколько чатов и перезапуск, светлая
  и тёмная тема, папки, фото, голос, настройки и уведомления, VoiceOver
  вживую. Ошибки — DEBUG
  launch-аргументами без правки кода:
  - `-mockOffline` — сообщение получает статус «Will send when online», после
    перезапуска без флага уходит само;
  - `-mockSlowStream` — «Stop» посреди ответа; `xcrun simctl terminate` во
    время стрима → после запуска ответ прерван, есть «Retry»;
  - `-mockError 429|401|403|500` — свой текст ошибки и «Retry»;
  - ещё `-mockData` (демо-чаты), `-mockDictation`, `-mockOnDeviceModel`.
- Unit-тесты (Swift Testing): SSE-парсер, маппинг ошибок, Groq-провайдер на
  заглушке транспорта, `ChatService` с фейками (стриминг, троттлинг записи,
  outbox без двойной отправки, «Stop», «Retry»), контрактные тесты репозитория
  — одни и те же для in-memory и GRDB, миграции, Markdown-парсер, ViewModel,
  форма и маскировка ключа, полнота русского перевода.
- UI-тесты (XCUITest): переименование и удаление через алерты, папки,
  скрытие клавиатуры.
