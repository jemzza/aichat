# AI-логи

Транскрипты работы с Claude Code над этим проектом — для оценки того, как
велась работа с AI.

| Файл | Что внутри |
|---|---|
| `<дата>_<id>.md` | Читаемый лог: запросы, ответы, вызовы инструментов и их результаты (свёрнуты) |
| `<дата>_<id>.jsonl` | Те же сообщения в машинном виде |

## Как обновлять

После каждого раздела плана (`docs/plan.md`) и перед сдачей:

```bash
python3 scripts/export_ai_logs.py
```

Скрипт берёт транскрипты проекта из `~/.claude/projects/…`, перезаписывает
файлы здесь и в конце сам проверяет результат (`--check` — только проверка).
Коммитить только при «✓ ai-logs чистые».
